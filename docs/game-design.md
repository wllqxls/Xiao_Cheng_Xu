# 游戏设计初稿

## 结论

第一阶段采用 `Restore Mode`：世界已经被虚构异象侵蚀，玩家不是制造灾难，而是作为修复者，通过区域净化、屏障建设、资源调度和事件抉择，让地图逐步恢复稳定。

`Spread Mode` 暂时只作为后续扩展，不进入 MVP。原因是双模式会让数值、UI、教程和胜负条件翻倍，第一阶段容易失焦。

## 工作标题

候选名：

- 《归明计划》
- 《静界修复署》
- 《雾后灯塔》
- 《回声清理局》

当前默认使用：《归明计划》。

## 原创世界观

大陆被一种名为 `Dusk Veil` 的虚构现象覆盖。它不是病毒，也不是现实疾病，而是一种会扰乱地形、记忆和城市设施的异常雾层。

玩家所属组织是 `Lumen Bureau`，负责重新点亮区域节点、恢复路线、建立静界屏障，并处理各地传来的突发情况。

## 核心循环

1. 观察竖版海陆地图。
2. 点击区域查看状态、风险、收益和邻接关系。
3. 根据区域类型选择修复、隔离、封锁航线、侦测或等待。
4. 每回合结算区域变化、资源收入、陆地侵蚀和航线传播。
5. 随机事件出现，玩家做短决策。
6. 升级全局能力。
7. 达成全图恢复或被侵蚀反扑导致失败。

## 地图方向

MVP 地图采用“手绘航海世界地图 + 桌游式区域规则”的混合方向。

- 画面主体是竖版原创海陆地图，不使用现实国家、真实大陆或真实城市地图。
- 海洋提供空间感，陆地承载主要侵蚀状态。
- 陆地包含多元区域：核心城市、港口城市、森林、山地、农田、工业区、科技院、机场枢纽、群岛、研究站。
- 飞机、船只和航线作为传播风险线索，不需要精细建模，但要带轻微侵蚀颜色提示。
- 侵蚀表现从小红点开始，逐渐变成红斑，再升级为区域半透明红色覆盖。
- 人口密集区红点更密，森林表现为蔓延纹路，工业区表现为烟尘状红斑，港口和机场更容易出现跨区传播。

## 区域差异

区域类型会同时影响视觉和传播规则：

- 核心城市、港口城市、机场枢纽人口和流动性更高，传播压力更大。
- 港口、机场、海上航线会提高跨区传播风险。
- 工业区有中高传播压力，适合设计烟尘状侵蚀表现。
- 森林、山地、研究站相对更稳，但一旦被侵蚀，视觉上要有明显蔓延痕迹。
- 农田带作为中性区域，用来承接城市和自然区之间的过渡。

## 区域状态

- `unaffected`：未影响。区域稳定，可产生基础资源。
- `latent`：潜伏。暂未明显失控，但存在风险。
- `spreading`：扩散中。会影响邻接区域。
- `severe`：严重。资源收益下降，扩散风险高。
- `controlled`：被控制。暂时压制风险，但还未恢复。
- `clearing`：清除中。正在恢复，若持续投入可转为稳定。

## 玩家资源

默认资源名：`Lumen`，中文显示为“明烬”。

用途：

- 区域修复。
- 建立屏障。
- 升级能力。
- 处理事件。

来源：

- 稳定区域产出。
- 特定升级增加产出。
- 事件奖励。
- 完成区域恢复奖励。

## 胜利条件

MVP 胜利条件：

- 所有区域达到 `unaffected` 或 `controlled`。
- 全局风险低于指定阈值。
- 至少完成一次关键事件链。

## 失败条件

MVP 失败条件：

- 全局风险达到 100%。
- 严重区域数量超过地图区域总数的 70%。
- 资源连续若干回合无法支付最低维护成本。

## 操作方式

- 单指点击地图区域：查看详情。
- 底部面板按钮：执行修复、隔离、侦测、封锁航线、升级。
- 事件弹窗：二选一或三选一。
- 顶部轻量数据显示：天数、资源、全局风险、恢复进度。

## 交通管控

玩家可以对带有港口、机场或海上航线的区域执行交通管控。管控会消耗明烬，并在 3 天内降低该区域作为传播源和传播目标的风险。

- 港口和海上航线适合表现为船只、码头和海路风险。
- 机场适合表现为飞机尾迹和空中路线风险。
- 没有港口、机场或航线的区域不能执行交通管控。
- 交通管控不等于区域恢复，只是争取修复时间。

## UI 方向

- 地图占上方主视觉。
- 下半屏放详情面板和主要操作。
- 不做大段说明页。
- 教程只在第一次遇到功能时弹出一小步。

## 美术方向

关键词：手绘航海图、海洋、原创陆地、城市群、森林、港口、航线、低饱和底图、高对比状态反馈。

主风格不走科技雷达地图。地图可以有少量先进城市或研究站，但整体视觉应是“有人生活的海陆世界”，而不是单纯监控界面。

不要使用现实城市地图、现实医疗符号、血液、病菌、病毒图标。
