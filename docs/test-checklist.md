- [ ] 场景能打开。
- [ ] 竖屏布局正确。
- [ ] 地图显示完整。
- [ ] 区域点击命中准确。

- [ ] 事件能触发并完成选择。

- [x] 资源路径正确。

- [ ] 本地存档正常。
- [ ] 退出重进可继续。
- [x] 包体大小符合阶段目标。

已知说明：

- 微信开发者工具控制台可能出现 `webapi_getwxaasyncsecinfo:fail`，当前判断为工具或微信 SDK 侧报错，不是项目脚本初始化错误。
- 画布内按钮不是原生可访问控件，自动化工具难以稳定点选；交互项仍需 Cocos 预览、手动点击或真机验证。
