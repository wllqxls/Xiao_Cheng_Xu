# 测试清单

## Cocos 预览

- [ ] 场景能打开。
- [ ] 竖屏布局正确。
- [ ] 地图显示完整。
- [ ] 区域点击命中准确。
- [ ] 底部面板不遮挡关键地图反馈。
- [ ] 资源数值会变化。
- [ ] 升级按钮成本和等级正确。
- [ ] 事件能触发并完成选择。
- [ ] 胜利条件能触发。
- [ ] 失败条件能触发。
- [ ] 音效能播放和关闭。
- [ ] 存档能写入和读取。

## 微信开发者工具

- [ ] 构建目录能被微信开发者工具打开。
- [ ] 首次启动无报错。
- [ ] 资源路径正确。
- [ ] 音频播放正常。
- [ ] 本地存档正常。
- [ ] 退出重进可继续。
- [ ] 包体大小符合阶段目标。
- [ ] 没有控制台敏感信息。

## 真机微信

- [ ] 竖屏适配正常。
- [ ] 刘海屏和底部安全区不遮挡按钮。
- [ ] 单手点击主要按钮舒适。
- [ ] 地图拖动或点击不卡顿。
- [ ] 低端机帧率可接受。
- [ ] 音量和静音设置生效。
- [ ] 异常退出后可恢复进度。
- [ ] 网络较差时不影响单机游玩。

## 玩法验证

- [ ] 玩家 1 分钟内能理解基本操作。
- [ ] 玩家 3 分钟内能看到区域状态变化。
- [ ] 玩家能理解资源为什么增加或减少。
- [ ] 玩家能理解升级带来的效果。
- [ ] 玩家能理解事件选择后果。
- [ ] 胜负结果有清楚反馈。

## 素材验证

- [ ] 素材命名符合规则。
- [ ] AI 素材有提示词和授权记录。
- [ ] 图片已压缩。
- [ ] 音频音量统一。
- [ ] 循环音没有明显断点。
